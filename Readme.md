## Лабораторная работа № 4

Модернизация сайта CandleCraft (из ЛР2) с использованием современного CSS и ООП на JavaScript.

**Что сделано:**
- **Flexbox** — главная страница (шапка, блок преимуществ).
- **CSS Grid** — каталог (сетка карточек товаров).
- **CSS-переменные** — все цвета вынесены в `:root` в `style.css`.
- **Анимация** — плавное появление заголовка на главной (`@keyframes fadeIn`).
- **Форма** — страница `lab4/contact.html` (поля: text, email, select, radio, textarea, checkbox).
- **ООП на JS** — класс `OrderForm` с конструктором и методом `print()` в `lab4/js/script.js`. При отправке формы создаётся объект и выводится в консоль браузера.
- **БЭМ** — все классы названы по методологии (например, `header__logo`, `product-card__price`).
